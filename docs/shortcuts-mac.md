# Dejima KVM — Mac ショートカットリファレンス

> このドキュメントは Mac ホストアプリ用です。Windows 版はキーバインドが異なります。

## キャプチャモード

映像エリアをクリックするとキャプチャモードに入り、キー入力がリモート（RPi）に転送されます。

| 操作 | 説明 |
|------|------|
| 映像エリアをクリック | キャプチャ開始 |
| `Esc` | キャプチャ解除（リモートには送られない） |
| 映像エリア外をクリック | キャプチャ解除 |

ウィンドウタイトルに「Input captured (Esc to release)」と表示されているときがキャプチャ中です。

## キーボード直接操作（キャプチャ中）

### Cmd → Ctrl 自動変換

Mac の `Cmd` キーはリモート Linux の `Ctrl` に自動変換されます。Mac 上で普段どおりのショートカットを押せば、リモートでは Ctrl コンボとして動作します。

| Mac で押すキー | リモートに送られるキー | 用途 |
|----------------|----------------------|------|
| `Cmd+A` | `Ctrl+A` | 全選択 |
| `Cmd+Z` | `Ctrl+Z` | 元に戻す |
| `Cmd+S` | `Ctrl+S` | 保存 |
| `Cmd+T` | `Ctrl+T` | 新しいタブ |
| `Cmd+W` | `Ctrl+W` | タブを閉じる |
| `Cmd+L` | `Ctrl+L` | アドレスバーへ移動 |
| `Cmd+F` | `Ctrl+F` | 検索 |
| `Cmd+←` | `Alt+←` | ブラウザ「戻る」 |
| `Cmd+→` | `Alt+→` | ブラウザ「進む」 |
| `Cmd+Option+←` | `Ctrl+Shift+Tab` | 前のタブへ |
| `Cmd+Option+→` | `Ctrl+Tab` | 次のタブへ |
| `Cmd+`*任意のキー* | `Ctrl+`*同じキー* | その他すべて同様 |

> **注意**: `Cmd`（Meta/Super）キー単体はリモートに送信されません。Linux の Super キーを送りたい場合は、将来的に Send Key メニューに追加が必要です。

### クリップボード連携

| Mac で押すキー | 動作 |
|----------------|------|
| `Cmd+C` | リモートに `Ctrl+C` を送信 → 300ms 後にリモートのクリップボードを取得し、Mac のクリップボードにコピー |
| `Cmd+V` | Mac のクリップボードにテキストがあれば、そのテキストをリモートへ Paste モードで送信。空の場合は `Ctrl+V` をそのまま送信 |

### その他のキー

以下のキーはそのままリモートに転送されます:

- 英数字・記号キー
- `Tab`, `Enter`, `Backspace`, `Delete`
- `Shift`, `Ctrl`, `Alt`（Option）
- 矢印キー、`Home`, `End`, `PageUp`, `PageDown`
- ファンクションキー（`F1`〜`F12`）
- `CapsLock`, `NumLock`
- 日本語入力関連キー（`かな`, `英数`, `変換`, `無変換`）

## Tools > Send Key メニュー

Mac キーボードから直接押せない、またはホストアプリが横取りするキーをリモートに送信します。

| メニュー項目 | 送信されるキーコンボ |
|-------------|-------------------|
| Escape | `Escape`（キャプチャ中は Esc でキャプチャ解除になるため、メニュー経由で送る） |
| Ctrl+Alt+Delete | `Ctrl+Alt+Delete` |
| Alt+Tab | `Alt+Tab` |
| Alt+F4 | `Alt+F4` |
| PrintScreen | `PrintScreen` |
| Insert | `Insert` |
| ScrollLock | `ScrollLock` |
| Pause/Break | `Pause` |

## Tools > Type Text ダイアログ

IME（日本語入力）を含む任意のテキストをリモートに送信するためのダイアログです。メニューバーの **Tools > Type Text...** から開きます。

### 使い方

1. ダイアログが開いたらテキストエリアに文字を入力（IME 使用可）
2. 送信モードを選んで実行

### 送信モード

| モード | ボタン | ショートカット | 動作 | 推奨用途 |
|--------|--------|---------------|------|---------|
| Type | 「Type」ボタン | `Cmd+Enter` | wtype/xdotool 経由で1文字ずつ入力 | ターミナル、テキストエディタ |
| Paste | 「Paste」ボタン | `Cmd+Shift+Enter` | wl-copy でクリップボードに設定 → `Ctrl+V` を送信 | ブラウザ、GUI アプリ |

### ダイアログ操作

| キー | 動作 |
|------|------|
| `Esc` | ダイアログを閉じる |
| `Cmd+Enter` | Type モードで送信 |
| `Cmd+Shift+Enter` | Paste モードで送信 |

## Tools > Get Clipboard

メニューバーの **Tools > Get Clipboard** を選択すると、リモートのクリップボード内容を取得して Mac のクリップボードにコピーします。

## 送れないキー・制限事項

- **Cmd（Super/Meta）単体**: リモートに送信されません。Cmd+key コンボは Ctrl+key に変換されますが、Super キー単体の送信は現在非対応です。
- **Escape**: キャプチャ中は常にキャプチャ解除として扱われ、リモートには送られません。リモートに Escape を送るには **Tools > Send Key > Escape** を使ってください。
- **キーリピート**: キーリピートイベントは無視されます（最初の押下のみ送信）。
- **IME 直接入力**: キャプチャ中の IME composing イベントは無視されます。日本語入力は **Tools > Type Text** ダイアログを使ってください。
- **Mac 固有のショートカット**: `Cmd+Q`（アプリ終了）、`Cmd+H`（隠す）、`Cmd+M`（最小化）などの macOS システムショートカットはホスト OS が処理するため、リモートには転送されません。
